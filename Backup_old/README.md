# Backup da versão estática

Esta pasta contém a versão anterior do site, baseada em HTML, CSS e JavaScript puros.

Ela é mantida somente como referência e não participa do build, do desenvolvimento ou da publicação da aplicação Next.js atual.

Para alterar o site ativo, use exclusivamente as pastas `app`, `components`, `lib` e `public` localizadas na raiz do projeto.
