Política de Privacidade

Última atualização: agosto de 2026.

Quais dados são solicitados

O formulário pode solicitar nome, contato, tipo de negócio, serviço de interesse e uma descrição do objetivo do projeto.

Como os dados são utilizados

As informações são usadas somente para responder à solicitação, preparar uma proposta e dar continuidade ao atendimento comercial.

Envio pelo WhatsApp

Ao enviar o formulário, uma mensagem é preparada e aberta no WhatsApp. O envio somente acontece após a confirmação do próprio usuário. A utilização do WhatsApp também está sujeita às políticas da plataforma.

Armazenamento e compartilhamento

Esta versão do site não mantém banco de dados próprio para o formulário. Os dados não são vendidos. Eles podem permanecer no histórico do canal escolhido para o atendimento.

Medição de campanhas

O site está preparado para receber ferramentas de medição, como Google Analytics e Google Ads. Quando essas ferramentas forem ativadas, esta política deverá ser revisada para refletir os dados e cookies efetivamente utilizados.

Contato e solicitações

Para solicitar informações, correção ou exclusão de dados enviados durante o atendimento, escreva para marcosmendes.dev@gmail.com.
